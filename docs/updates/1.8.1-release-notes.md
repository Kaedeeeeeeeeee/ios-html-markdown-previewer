# 1.8.1 release notes

English, Simplified Chinese, Japanese, and Traditional Chinese are prepared in
`fastlane/metadata/{en-US,zh-Hans,ja,zh-Hant}/release_notes.txt`. They describe
the iPhone Duo and reader polish from #25, recorded in
[the October 8 update](2026-10-08-duo-ux-polish.md): the one-line preview status
and single-row search on the outer display, the library's row of open actions
and titled toolbar symbols, one-line JSON/YAML fields and the outline column on
larger displays, fold-aware library and search placement when partially open,
and the iOS 27.1 Find toolbar action. Name, subtitle, description, keywords,
promotional text, and URLs are unchanged from 1.8. The UI test fixes in #26 are
not user-facing and are not mentioned.

UI names follow the app's own strings in each language (Open File, Open ZIP
Package, Paste to Preview, Table of Contents, Find in Document).

The wording does not promise more than #25 verified. Toolbar Find is limited to
iOS 27.1, where it was exercised only on iPhone Duo. In partially open poses a
selected search result is moved clear of the fold; results the reader has
scrolled away from are not pulled back. The single-row search is described only
for the outer display, where it was verified.
