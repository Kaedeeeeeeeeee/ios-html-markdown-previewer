# 1.8 release notes

English, Simplified Chinese, Japanese, and Traditional Chinese are prepared in
`fastlane/metadata/{en-US,zh-Hans,ja,zh-Hant}/release_notes.txt`. They describe Duo
layout, reading/search continuity, compact JSON/YAML keyboard layouts, sharing,
and Paste/Settings navigation. These active notes were uploaded and verified
against App Store Connect, then submitted with 1.8 (13) on 2026-10-07. The version
is Waiting for Review; approval and public release are still pending.

The update also includes locally gated rating requests. These use on-device
reading history and Apple's system review interface; no analytics service or
document upload is added. This is included in release scope but is not promoted
as a user-facing reading feature in the notes.

The wording does not promise that the software keyboard remains visible in
every Duo pose, that arbitrary user-scrolled-away results are pulled back into
view, or that rotation during initial PDF generation has been verified.

Traditional Chinese is included in the 1.8 metadata and screenshot inventory.
Its original candidate remains as a preparation record. Exact remote read-back
passed for all 32 active metadata fields before review submission. See the
[release checklist](../release-checklist-1.8.md) for CI and submission evidence.

Historical 1.7 notes, acceptance records, screenshots, and ASO provenance are
retained as historical records.
