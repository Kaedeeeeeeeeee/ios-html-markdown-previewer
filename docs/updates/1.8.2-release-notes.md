# 1.8.2 release notes

English, Simplified Chinese, Japanese, and Traditional Chinese are prepared in
`fastlane/metadata/{en-US,zh-Hans,ja,zh-Hant}/release_notes.txt`. 1.8.2 (15)
ships the app code of 1.8.1 (14) unchanged; its purpose is to replace the store
screenshots, which App Store Connect does not allow to change on a version that
is already Ready for Distribution. The notes therefore only mention the
refreshed screenshots and the existing on-device processing. Name, subtitle,
description, keywords, promotional text, and URLs are unchanged from 1.8.1.

The product page header and search results art were approved as standalone
creative assets on 2026-10-30 and published on 1.8.1; they do not depend on
this version.

## Screenshots

Screenshots recomposed from 1.8 (13) captures.

All 72 images (four locales, three families, six scenes) are the redesigned set

enlarged device and a zoomed callout of the real UI. They are uploaded for this
version with `scripts/asset-library/upload_assets.py`, so their reference names
use 1.8.2, while their capture records stay 1.8 (13).
