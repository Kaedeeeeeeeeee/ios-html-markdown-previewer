# 1.9.0 release notes

1.9.0 (17) adds three preview formats and replaces 1.8.3 (16), which was
withdrawn from App Review before release. It therefore also carries the 1.8.3
search metadata (YAML subtitles, fuller keywords, en-GB and es-MX text-only
localizations).

What's New is prepared in
`fastlane/metadata/{en-US,zh-Hans,ja,zh-Hant}/release_notes.txt`; the two
text-only localizations have their own copies in
`fastlane/metadata/{en-GB,es-MX}/release_notes.txt`:

- Mermaid diagram files (`.mmd`, `.mermaid`) open as diagrams, drawn offline
  with the bundled Mermaid renderer.
- CSV and TSV files open as tables with delimiter detection and right-aligned
  number columns (first 500 rows; raw text shows every row).
- SVG files show as images through `<img>`, so their scripts, links, and remote
  resources are not loaded.
- New built-in Mermaid, CSV, and SVG samples.

The descriptions gain a "Diagrams, tables, and images" section, list the new
extensions and samples, and the promotional text names the new formats.
Subtitles and keywords are unchanged from 1.8.3.
