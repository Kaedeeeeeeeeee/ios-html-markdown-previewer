# 1.8.3 release notes

English, Simplified Chinese, Japanese, and Traditional Chinese are prepared in
`fastlane/metadata/{en-US,zh-Hans,ja,zh-Hant}/release_notes.txt`; the two new
store localizations have their own copies in
`fastlane/metadata/{en-GB,es-MX}/release_notes.txt`. 1.8.3 (16) ships the app
code of 1.8.2 (15) unchanged. Its purpose is a search metadata update, which App
Store Connect only accepts with a new version:

- New subtitles and fuller keyword fields for en-US, zh-Hans, ja, and zh-Hant.
  The subtitles name YAML instead of ZIP; ZIP moves into the keywords.
- New en-GB localization (indexed in the UK, Australia, China mainland, Taiwan,
  and Hong Kong storefronts, which do not index en-US).
- New es-MX localization (also indexed in the US storefront).

The rationale is in the ASO plan of 2026-11-22. en-GB and es-MX have text
metadata only; App Store Connect shows the primary-language screenshots for
them. The app interface remains English, Japanese, and Chinese, which the es-MX
description states.
